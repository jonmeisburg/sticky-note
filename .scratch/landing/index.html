Omarchy · Arch + Hyprland + quickshell

One note, tiled in with everything else.

sticky-note is a single persistent markdown note for your desktop. It spawns as a real compositor window — resize it, tile it, restart your shell — and your text is already saved.

$ git clone https://github.com/jonmeisburg/sticky-note ~/.config/omarchy/plugins/sticky-note
~/.config/sticky-note/note.json FloatingWindow

click the note to edit · Ctrl+B bolds · Esc commits

Why it feels right

It behaves like a window, because it is one.

Real window

Tiles, resizes, remembers

Not a wallpaper overlay — a floating window your compositor actually manages. Tile it beside your editor, drag it to a corner, restart the shell. Geometry is observed from Hyprland and written back, so the note reopens exactly where you left it.

Two-face bold

Focus is the mode

While you type, you see the raw source with its ** markers. Click away and it renders as markdown. No toolbar, no toggle — active focus edits, focus loss commits, and so does Escape. Try it on the note above.

Hard to lose

Written carefully, or not at all

Text saves (debounced) to ~/.config/sticky-note/note.json and external edits are picked up live. A corrupt file is never overwritten — it's preserved as note.json.invalid-* while a clean note starts beside it. Nothing is written before the first read completes.

Install

Two commands, then it's just there.

Install
$ git clone https://github.com/jonmeisburg/sticky-note \
      ~/.config/omarchy/plugins/sticky-note
$ omarchy restart shell
Hack on it — hot-reloading, throwaway state
$ STICKY_NOTE_STATE=/tmp/note.json quickshell -p .
# your real note at ~/.config/sticky-note/note.json is never touched

Under the hood

The QML view only applies results. Every decision — document validation and defaults, the size floors, the bold caret map that refuses to guess — lives in plain ES modules under logic/, exercised by node tests.

Compositor behavior wasn't unit-tested into existence: each acceptance ticket was demonstrated against the live desktop, driving the real note through Hyprland and asserting on the state file.
